# Live

Правила игры Live. Сайт: <https://caseyjohnson-rs.github.io/Live/>

```bash
uv run mkdocs serve
```

## Как писать правила

- **Правила читаются последовательно.** Глава опирается только на
  предыдущие: никаких ссылок вперёд и «см. ниже».
- **Термин вводится один раз** — там, где впервые понадобился, и
  помечается как определение:

  ```markdown
  Перед игроками лежит **каморный ряд**{ #каморный-ряд .term } — ...
  ```

  После этого термин попадает в [глоссарий](docs/rules/glossary.md) со ссылкой
  на место определения.
- **Никаких технических деталей.** Правила описывают игру, а не то, как
  её реализует программа.
