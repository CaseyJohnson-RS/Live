# Глоссарий

Термины, которые вводятся в правилах. Каждый ведёт туда, где он
определён.

[Активный игрок](rules/shot.md#t-активный-игрок)
:   Тот, чей сейчас ход.

[Вес](rules/chips.md#t-вес)
:   Единица плюс все фишки на каморе. Чем тяжелее камора, тем охотнее в неё ложится патрон.

[Выдача](rules/hand.md#t-выдача)
:   Раздача новых предметов в начале расклада и выбор руки.

[Выстрел](rules/shot.md#t-выстрел)
:   Главное действие хода: камора и цель на выбор.

[Гибель](rules/shot.md#t-гибель)
:   Жизни кончились: игрок больше не ходит и не может быть целью.

[Жизнь](rules/table.md#t-жизнь)
:   Попадание отнимает одну. В начале раунда у всех поровну.

[Заряженная камора](rules/table.md#t-заряженная-камора)
:   Камора с патроном.

[Зарядка](rules/spread.md#t-зарядка)
:   Распределение патронов по каморам в начале расклада — по весам.

[Игра](rules/round.md#t-игра)
:   Серия раундов с одним составом игроков.

[Игрок](rules/table.md#t-игрок)
:   Участник игры. За столом их от двух до шести.

[Камора](rules/table.md#t-камора)
:   Место в каморном ряду: заряженная или пустая.

[Каморный ряд](rules/table.md#t-каморный-ряд)
:   Каморы, выложенные в линию. Порядок виден всем, содержимое — нет.

[Класс](rules/hand.md#t-класс)
:   Сила и редкость предмета: обычный, редкий или потолочный.

[Лимит руки](rules/hand.md#t-лимит-руки)
:   Сколько предметов можно держать в руке.

[Отстрелянная камора](rules/shot.md#t-отстрелянная-камора)
:   Камора, из которой уже выстрелили. Её содержимое открыто.

[Патрон](rules/table.md#t-патрон)
:   То, что лежит в заряженной каморе.

[Подготовка](rules/hand.md#t-подготовка)
:   Начало расклада до первого хода: выдача, ставки, зарядка.

[Попадание](rules/shot.md#t-попадание)
:   Выстрел из заряженной каморы: цель теряет жизнь.

[Предмет](rules/hand.md#t-предмет)
:   То, что игрок держит в руке и применяет в свой ход.

[Пул](rules/chips.md#t-пул)
:   Фишки, заработанные за расклад, — на ставки в следующем.

[Пустая камора](rules/table.md#t-пустая-камора)
:   Камора без патрона.

[Расклад](rules/spread.md#t-расклад)
:   Время жизни одного каморного ряда.

[Раунд](rules/round.md#t-раунд)
:   Расклады до тех пор, пока не останется один живой игрок.

[Рука](rules/hand.md#t-рука)
:   Предметы игрока. Видна всем.

[Ставка](rules/chips.md#t-ставка)
:   Фишки, поставленные на камору. Ставки делают одновременно и втайне.

[Фишка](rules/chips.md#t-фишка)
:   Награда за холостой выстрел в себя. Добавляет каморе вес.

[Ход](rules/shot.md#t-ход)
:   Очередь игрока действовать.

[Холостой](rules/shot.md#t-холостой)
:   Выстрел из пустой каморы: ничего не происходит.

[Цель](rules/shot.md#t-цель)
:   Живой игрок, в которого стреляют. Можно выбрать себя.

[Эффект](rules/hand.md#t-эффект)
:   След предмета на игроке, который сработает позже.
