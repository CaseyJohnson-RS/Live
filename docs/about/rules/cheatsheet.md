# Шпаргалка

Всё главное из правил — на одной странице.

## Твой ход

1. Применяй предметы — сколько хочешь, до выстрела.
2. Выбери неотстрелянную камору и живую цель — соперника или себя.
3. Выстрел: патрон — цель теряет жизнь; пусто — ничего.
4. Выстрелил в себя, холостой, а патроны в ряду ещё были — получи фишку.
5. Ход переходит к следующему живому.

## Расклад

1. Объявляется число камор.
2. Выдача предметов: каждый выбирает руку не больше лимита.
3. Ставки фишками: одновременно и втайне.
4. Ряд заряжается по весам: вес каморы — один плюс фишки на ней.
5. Объявляется число патронов.
6. Ходы — пока из каждой каморы не выстрелят.

## Раунд и игра

- Раунд — пока не останется один живой. Он побеждает.
- Между раскладами сохраняется всё: жизни, рука, эффекты, пул фишек.
- Между раундами не сохраняется ничего.
- Игра — серия раундов; побеждает тот, кто выиграл больше всех.

## Кто что знает

| Что | Кто знает |
| --- | --- |
| Жизни, руки и эффекты каждого игрока | все |
| Сколько в ряду камор и патронов в начале расклада | все |
| Содержимое отстрелянных камор | все |
| Выстрелы: кто, в кого, из какой каморы, что вышло | все |
| Кто получил фишку и сколько у кого фишек | все |
| Применения предметов | все, если в описании не сказано иначе |
| Что выпало при выдаче и какую руку выбрал игрок | только он — пока выбор не сделали все |
| Ставки игрока | только он сам |
| Итоговые веса камор | никто |
| Какие каморы заряжены | никто |
| Сколько патронов осталось | никто не объявляет — но каждый может сосчитать |
