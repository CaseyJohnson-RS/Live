# Правила

## Как читать

Главы идут по порядку, и каждая опирается только на то, что уже было
раньше. Прочитай их подряд — и сможешь играть.

- Термин выделяется так — <span class="term">каморный ряд</span> — там,
  где он появляется впервые. Все термины собраны в
  [глоссарии](../glossary.md).
- Выноска **«Пока — случай»** отмечает числа, которые ещё не выверены
  игрой: сейчас их выбирает случай.
- Выноска **«Совет»** — не правило, а подсказка, как этим правилом
  пользоваться.
