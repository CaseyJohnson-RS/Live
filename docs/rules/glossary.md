# Глоссарий

Термины, которые вводятся в правилах. Каждый ведёт туда, где он
определён.

[Активный игрок](shot.md#t-активный-игрок)
:   Тот, чей сейчас ход.

[Вес](chips.md#t-вес)
:   Единица плюс все фишки на каморе. Чем тяжелее камора, тем охотнее в неё ложится патрон.

[Выдача](hand.md#t-выдача)
:   Раздача новых предметов в начале раунда и выбор руки.

[Выстрел](shot.md#t-выстрел)
:   Главное действие хода: камора и цель на выбор.

[Гибель](shot.md#t-гибель)
:   Жизни кончились: игрок больше не ходит и не может быть целью.

[Жизнь](table.md#t-жизнь)
:   Попадание отнимает одну. В начале партии у всех поровну.

[Заряженная камора](table.md#t-заряженная-камора)
:   Камора с патроном.

[Зарядка](round.md#t-зарядка)
:   Раскладка патронов по каморам в начале раунда — по весам.

[Игра](match.md#t-игра)
:   Серия партий с одним составом игроков.

[Игрок](table.md#t-игрок)
:   Участник игры. За столом их от двух до шести.

[Камора](table.md#t-камора)
:   Место в каморном ряду: заряженная или пустая.

[Каморный ряд](table.md#t-каморный-ряд)
:   Каморы, выложенные в линию. Порядок виден всем, содержимое — нет.

[Класс](hand.md#t-класс)
:   Сила и редкость предмета: обычный, редкий или потолочный.

[Лимит руки](hand.md#t-лимит-руки)
:   Сколько предметов можно держать в руке.

[Отстрелянная камора](shot.md#t-отстрелянная-камора)
:   Камора, из которой уже выстрелили. Её содержимое открыто.

[Партия](match.md#t-партия)
:   Раунды до тех пор, пока не останется один живой игрок.

[Патрон](table.md#t-патрон)
:   То, что лежит в заряженной каморе.

[Подготовка](hand.md#t-подготовка)
:   Начало раунда до первого хода: выдача, раскладка, зарядка.

[Попадание](shot.md#t-попадание)
:   Выстрел из заряженной каморы: цель теряет жизнь.

[Предмет](hand.md#t-предмет)
:   То, что игрок держит в руке и применяет в свой ход.

[Пул](chips.md#t-пул)
:   Фишки, заработанные за раунд, — на раскладку в следующем.

[Пустая камора](table.md#t-пустая-камора)
:   Камора без патрона.

[Раскладка](chips.md#t-раскладка)
:   Распределение пула по каморам — одновременно и втайне.

[Раунд](round.md#t-раунд)
:   Время жизни одного каморного ряда.

[Рука](hand.md#t-рука)
:   Предметы игрока. Видна всем.

[Фишка](chips.md#t-фишка)
:   Награда за холостой выстрел в себя. Добавляет каморе вес.

[Ход](shot.md#t-ход)
:   Очередь игрока действовать.

[Холостой](shot.md#t-холостой)
:   Выстрел из пустой каморы: ничего не происходит.

[Цель](shot.md#t-цель)
:   Живой игрок, в которого стреляют. Можно выбрать себя.

[Эффект](hand.md#t-эффект)
:   След предмета на игроке, который сработает позже.
