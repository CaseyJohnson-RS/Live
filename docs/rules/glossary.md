# Глоссарий

Термины, которые вводятся в правилах. Каждый ведёт туда, где он
определён.

[Активный игрок](shot.md#активный-игрок)
:   Тот, чей сейчас ход.

[Выстрел](shot.md#выстрел)
:   Действие активного игрока: камора и цель на выбор.

[Гибель](shot.md#гибель)
:   Жизни кончились: игрок больше не ходит и не может быть целью.

[Жизнь](table.md#жизнь)
:   Попадание отнимает одну. У всех поровну.

[Заряженная камора](table.md#заряженная-камора)
:   Камора с патроном.

[Игра](match.md#игра)
:   Серия партий.

[Игрок](table.md#игрок)
:   Участник игры. За столом их от двух до шести.

[Камора](table.md#камора)
:   Место в каморном ряду: заряженная или пустая.

[Каморный ряд](table.md#каморный-ряд)
:   Каморы, выложенные в линию. Порядок виден всем, содержимое — нет.

[Отстрелянная камора](shot.md#отстрелянная-камора)
:   Камора, из которой уже выстрелили. Её содержимое открыто.

[Партия](match.md#партия)
:   Раунды до тех пор, пока не останется один живой игрок.

[Патрон](table.md#патрон)
:   То, что лежит в заряженной каморе.

[Попадание](shot.md#попадание)
:   Выстрел из заряженной каморы: цель теряет жизнь.

[Пустая камора](table.md#пустая-камора)
:   Камора без патрона.

[Раунд](round.md#раунд)
:   Время жизни одного каморного ряда.

[Ход](shot.md#ход)
:   Очередь игрока действовать.

[Холостой](shot.md#холостой)
:   Выстрел из пустой каморы: ничего не происходит.

[Цель](shot.md#цель)
:   Живой игрок, в которого стреляют. Можно выбрать себя.
