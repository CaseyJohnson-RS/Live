# Стол

За столом сидят от двух до шести **игроков**{ #игрок .term }.

## Жизни

У каждого игрока есть **жизни**{ #жизнь .term } — у всех поровну. Число
жизней каждого видят все.

## Каморный ряд

Перед игроками на столе лежит **каморный ряд**{ #каморный-ряд .term } —
несколько **камор**{ #камора .term }, выложенных в линию. Порядок камор
виден всем и не меняется: каждую можно назвать по её месту в ряду.

Камора бывает **заряженной**{ #заряженная-камора .term } — в ней лежит
**патрон**{ #патрон .term }, — или **пустой**{ #пустая-камора .term }.

Что лежит в какой каморе, не знает никто. Но сколько в ряду патронов,
известно всем: ряд выкладывается вслух, например «два патрона из
восьми». В ряду всегда есть хотя бы один патрон и хотя бы одна пустая
камора.

!!! note "Пока — случай"

    Сколько жизней, камор и патронов, в итоге будет определять правило.
    Пока игру ни разу не запускали, его заменяет случай:

    - **жизни** — от 1 до 5, одинаково для всех;
    - **каморы** — от 4 до 12;
    - **патроны** — от 1 до числа камор без одной.
