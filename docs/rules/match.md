# Партия и игра

## Партия

**Партия**{ #партия .term } идёт раунд за раундом, пока за столом не
останется один живой игрок. Он — победитель партии. Партия заканчивается
сразу, даже посреди раунда.

## Игра

**Игра**{ #игра .term } — серия партий. Сколько партий в игре, игроки
договариваются до её начала.

Каждая партия начинается с чистого листа: все игроки снова живы, жизни
раздаются заново, круг очереди снова выбирается жребием.
