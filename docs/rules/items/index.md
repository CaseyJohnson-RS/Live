# Каталог предметов

Все предметы игры, сгруппированные по тому, на что они действуют.
Общие правила — как предметы выдаются и применяются — в главе
[«Предметы»](../hand.md).

<span class="cls cls--rare">редкий</span>
<span class="cls cls--ceiling">потолочный</span>

!!! note "Черновик"

    Каталог перенесён из старого свода правил и ещё не выверен игрой.

## Знание

Предметы, которые подсказывают, что происходит в ряду. То, что они
показывают, видит только применивший; остальные видят лишь, что предмет
применён и на какую камору.

### Одним глазом <span class="cls cls--common">обычный</span> { #одним-глазом data-toc-label="Одним глазом" }

Показывает применившему вес одной выбранной каморы.

### Во все глаза <span class="cls cls--ceiling">потолочный</span> { #во-все-глаза data-toc-label="Во все глаза" }

Показывает применившему вес каждой каморы ряда.

## Ряд

Предметы, которые меняют сам ряд. После них число оставшихся патронов
уже не всегда можно сосчитать точно.

### Реверс <span class="cls cls--common">обычный</span> { #реверс data-toc-label="Реверс" }

Переворачивает выбранную неотстрелянную камору: заряженная становится
пустой, пустая — заряженной. Каким стало содержимое, не знает никто,
даже применивший.

### Хочу ещё <span class="cls cls--common">обычный</span> { #хочу-ещё data-toc-label="Хочу ещё" }

Добавляет в ряд один патрон. Он ложится в одну из пустых
неотстрелянных камор — выбор идёт по весам, как при зарядке. Если пустых
камор нет, предмет тратится впустую.

### Мне страшно <span class="cls cls--common">обычный</span> { #мне-страшно data-toc-label="Мне страшно" }

Убирает из ряда один патрон. Его снимают с одной из заряженных
неотстрелянных камор — выбор идёт обратно весам: тяжёлую камору
разряжают реже. Если патронов в ряду нет, предмет тратится впустую.

### Что тут у нас <span class="cls cls--common">обычный</span> { #что-тут-у-нас data-toc-label="Что тут у нас" }

Отстреливает выбранную камору без выстрела: её содержимое открывается
всем, но никто не теряет жизнь и фишку никто не получает. Ход не
передаётся. Если это была последняя камора ряда, раунд заканчивается.

### ХАХхаахХАх <span class="cls cls--ceiling">потолочный</span> { #хаххааххах data-toc-label="ХАХхаахХАх" .keep-case }

Встряхивает ряд: все оставшиеся патроны заново раскладываются по
неотстрелянным каморам — по тем же весам, что при зарядке. Число
патронов не меняется, меняется только то, где они лежат.

## Жизни

### Глоток воды <span class="cls cls--common">обычный</span> { #глоток-воды data-toc-label="Глоток воды" }

Восстанавливает применившему одну жизнь — но не выше, чем было в начале
партии.

### Сомнительное удовольствие <span class="cls cls--common">обычный</span> { #сомнительное-удовольствие data-toc-label="Сомнительное удовольствие" }

Бросок наудачу: с шансом 50% восстанавливает применившему две жизни (не
выше, чем было в начале партии), с шансом 50% — отнимает одну. Может
убить. Фишку не приносит.

### Как новый <span class="cls cls--ceiling">потолочный</span> { #как-новый data-toc-label="Как новый" }

Восстанавливает применившему все жизни — столько, сколько было в начале
партии.

## Ход

### Пасс <span class="cls cls--common">обычный</span> { #пасс data-toc-label="Пасс" }

Передаёт ход следующему живому игроку без выстрела.

### Дубль <span class="cls cls--rare">редкий</span> { #дубль data-toc-label="Дубль" }

Оставляет эффект: следующий выстрел применившего в этот ход не передаёт
ход — после него можно выстрелить ещё раз.

### Со всей дури <span class="cls cls--rare">редкий</span> { #со-всей-дури data-toc-label="Со всей дури" }

Оставляет эффект: следующее попадание применившего — в любую цель —
отнимает не одну жизнь, а две.

### Настроечный щит <span class="cls cls--rare">редкий</span> { #настроечный-щит data-toc-label="Настроечный щит" }

Оставляет эффект: следующее попадание в применившего не отнимает жизнь.
Эффект держится до начала его следующего хода.

## Соперники

### Попробуй вот эту <span class="cls cls--rare">редкий</span> { #попробуй-вот-эту data-toc-label="Попробуй вот эту" }

Применивший называет игрока и камору. В свой следующий ход этот игрок
обязан стрелять именно из неё. Если камору отстреляют раньше,
ограничение снимается.

### Подыграй мне <span class="cls cls--ceiling">потолочный</span> { #подыграй-мне data-toc-label="Подыграй мне" }

Применивший называет игрока и цель. В свой следующий ход этот игрок
обязан стрелять именно в неё; камору он выбирает сам. Если цель к тому
времени погибла, ограничение снимается. В дуэли почти бесполезен:
выбирать там и так не из кого.

### Пора делиться <span class="cls cls--rare">редкий</span> { #пора-делиться data-toc-label="Пора делиться" }

Забирает у выбранного соперника на выбор применившего: либо случайный
предмет из его руки, либо одну фишку из тех, что он заработал в этом
раунде.

## Фишки

### Джекпот <span class="cls cls--ceiling">потолочный</span> { #джекпот data-toc-label="Джекпот" }

Добавляет применившему три фишки в пул на следующий раунд — без всякого
риска. Единственный способ получить фишки, не рискуя.
