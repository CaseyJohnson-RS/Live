# Раунд

**Раунд**{ #раунд .term } — время жизни одного каморного ряда. Он
начинается, когда ряд выложен, и заканчивается, когда из каждой каморы
выстрелили.

Раунд идёт, даже если патроны в ряду уже кончились: игроки стреляют,
пока в ряду остаются каморы.

## Новый ряд

Когда раунд закончился, на стол выкладывается новый ряд — с новым
числом камор и патронов, — и начинается следующий раунд.

Жизни между раундами сохраняются. Очередь тоже: следующий раунд
продолжает тот, чей сейчас ход.
